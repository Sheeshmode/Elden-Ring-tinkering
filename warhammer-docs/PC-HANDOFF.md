# Handoff for a session on the PC

Paste this into a Claude Code session opened in the 40k project folder on the
PC. A cloud session cannot do these steps, because they need the source books.

Work one doc per session. Start from the index doc and update its row when
you finish: https://claude.ai/artifact/CsCP1a4uhPYzz2sXEcRPpk

## Do these in order

1. **Page conversion.** Confirm the printed-page conversion finished for
   Tyranids, Orks and Inquisition. An Oct 20 session recovered only 60 of 252
   Tyranids page edits. Finish any that are missing.
2. **Re-check quotes** in those three docs against the printed page with the
   quote checker.
3. **Unconfirmed quotes.** Open the Oct 21 verification log. For each of the
   69 unconfirmed quotes (of 2,028), fix it or remove it from its faction doc.
4. **Whole-doc counts.** Run the quote checker on every doc the index marks
   "No count": Inquisition, Sisters of Battle, Imperial Armour and White
   Dwarf, and the whole of Aeldari, Tyranids, Orks and Chaos Daemons. Write
   the result into each doc as a Verification line.
5. **Synthesis.** Check the five Rule 9 lines added on Nov 12 (from "A prison
   that does destroy" on) against the books.
6. **Paraphrase.** For each doc, read the connecting prose against the cited
   pages. Fix any claim the page does not support.
7. **OCR fixes.** Where a quote was corrected, mark the fix with brackets.
   Start with Astra Militarum.
8. **Per-quote status.** Save a table per doc: quote, cite, status (exact,
   OCR noise, read by hand). Keep the tables with the docs, not only on disk.
9. **Speakers.** Name the in-universe speaker where a quote is a character's
   or a faction's view.
10. **Tyranid souls.** Search the Tyranid and Genestealer Cult books for the
    souls theme. Add a souls section, then rename the doc to "Psykers, Belief
    & Souls — Tyranids and Genestealer Cults".
11. **Citation format.** Change "7th ed, p.N" and "(7th), p.N" to
    "(7th ed), p.N" in every doc. Aeldari, Orks and Chaos Daemons hold most
    of them. Do this with a script on exports, then re-verify.
12. **Labels.** Add Stated / Consistent / Inferred labels to the summary
    claims in each faction doc.
13. **Edition tables and contradictions.** Give each faction doc an
    edition-change table and a short "where the books disagree" section.
14. **Novels.** Widen novel coverage, or state the limit in each doc.
15. **Word files.** Re-export all docs to Word with links and the synthesis
    diagram. Open each one in Word once.
16. **Backup.** Copy the project folder (scripts, page maps, logs) to a
    second place.
17. **Rebuild** the search page and the narration page.
